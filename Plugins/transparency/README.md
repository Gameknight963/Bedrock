# Window Transparency

Enable this plugin, then restart Discord using Bedrock's restart button. The plugin's enable switch controls transparency directly.

Use a CSS theme with transparent backgrounds in Bedrock's Themes page. This plugin makes the window support transparency; it does not change Discord's CSS or fade text and images.

Disabling the plugin requires a restart to restore the window. On Windows, transparency uses a frameless window. Native title bars and fixes for resizing transparent windows will be handled separately.
