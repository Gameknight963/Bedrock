# DevTools

"Enables DevTools with Ctrl+Shift+I or F12. Press the shortcut again to close them. This is separate from the MCP Bridge plugin.

The plugin enables Electron's DevTools window option before Discord creates its windows and handles the shortcuts in the main process. Discord's files and settings are left untouched.

If you enable the plugin after Discord has started, restart through Bedrock once to apply the window option. Disabling removes the shortcut handlers immediately and closes tools opened by the plugin. Only restoring the original window option requires a restart.
